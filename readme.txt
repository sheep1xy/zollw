THE KEEPER
==========

Everything you need is inside poster.png. Nothing else will be given.
Download the original file. Do not screenshot it, resave it, or run it through
any app that recompresses images. Anything that changes the pixels destroys it.

The answer is a set of three coordinates. Submit them on the page, either as
numbers or with every number spelled out in words.
If you decode a spelled-out version, trailing Q letters are padding.

To check a spelled-out answer yourself: keep only the letters, uppercase them,
take the SHA-256. It must equal:
83d71662705af53b89b781b3c55cd520ce244feb83264034ca792d39f874a5b9

Tools are fair game. Guessing is not much use. Good luck.
